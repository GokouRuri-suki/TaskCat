## 快速启动

### Windows
双击 `start.bat`

### Linux
1. 给脚本添加执行权限：
   ```bash
   chmod +x start_for_linux.sh
   chmod +x java/mvnw
   ```

2. 运行启动脚本：
   ```bash
   ./start_for_linux.sh
   ```

3. 如果提示缺少虚拟环境，按 `y` 自动创建。

更多详细说明请查看 [README_LINUX.md](README_LINUX.md)
